# 证据与命令安全

## 风险分级

### L0：低风险只读

- 读取系统、内核、会话、硬件、驱动、服务和限定时间的日志
- 查看资源、socket、进程、cgroup、挂载点、设备和沙盒声明权限
- 运行明确只读的配置语法检查

仍需限定 boot、unit、PID、接口、设备、路径和输出量。避免递归扫描根目录或导出全部 journal。

### L1：敏感、昂贵或可能扰动时序

- core/vmcore、进程环境、详细 GPU dump、支持包
- `strace -p`、调试器、`perf`、eBPF、DRM/libinput 高日志级别
- tcpdump、蓝牙 HCI、PipeWire/WirePlumber debug 日志
- 压力测试、广泛文件扫描、长时间设备或性能采样

使用前说明敏感性、开销、时长、大小、保存位置和清理方式，并限定对象和采集上限。

### L2：可逆状态变更

- reload/restart 服务、用户服务、网络、蓝牙、Portal、PipeWire 或 display manager
- 临时 sysctl、路由、防火墙、日志级别、沙盒权限或内核启动参数
- 安装调试包、创建测试用户、启用 core/kdump、切换 X11/Wayland

先保存当前状态和未保存工作，提供回滚并取得授权。

### L3：中断性、破坏性或恢复复杂

- `kill -9`、重启/关机、隔离节点、停止图形会话
- 在线存储卸载、`fsck`、`xfs_repair`、分区/RAID/LVM/引导修复
- 卸载或替换驱动、刷固件、持久修改 GRUB/initramfs
- 删除数据/日志、递归改权限、重置整套桌面配置
- 禁用 Secure Boot、SELinux/AppArmor、ACPI 或刷新防火墙规则

只有目标、影响、备份、控制台/恢复通道和回滚条件明确，并取得授权后才能执行。

## 默认禁止的快捷排除法

- 不用重启、重装、清缓存、删除 socket/PID 文件或清空日志代替取证。
- 不对已挂载文件系统运行修复命令，不用写盘 `dd` 作为首轮磁盘检查。
- 不关闭 SELinux/AppArmor 来证明权限问题，不直接加载未经审核的 `audit2allow` 结果。
- 不盲目重装显卡驱动、生成 `xorg.conf`、重置 dconf/KDE 或套用通用内核参数。
- 不给沙盒开放整个主机文件系统，不默认把用户加入 `video`/`render` 等特权组。
- 不对不受信任二进制执行 `ldd`，优先使用 `readelf` 或 `objdump`。
- 不执行 `curl | sh`、未知脚本或自动上传客户数据的采集程序。

## 证据质量

- 保留原始时间戳、时区、boot/session、主机/容器、PID/TID、命令和退出码。
- 日志保留故障窗口前后文；首次异常通常比连锁错误更有价值。
- 动态数据采样多次；单个 `top`、`vmstat` 或延迟点不能代表趋势。
- 对照节点必须在版本、配置、流量和资源条件上可比，一次只改变一个变量。
- 记录命令不存在、权限不足、日志轮转、目标重启或图片模糊等限制。

## 隐私与客户数据

- 图片可能包含姓名、客户名、邮箱、桌面通知、文件名和业务界面。
- `/proc/<pid>/environ`、命令行、core 和服务环境可能包含密码、Token 和证书材料。
- pcap、Portal/应用日志和支持包可能包含业务载荷、IP、用户名、路径和文档内容。
- 分享前脱敏密钥、Cookie、Authorization header、个人数据和客户标识，同时保留定位所需的时间、结构和错误码。
- 明确产物目录、访问权限、保留时间、校验值和删除方法。

## 命令呈现

每组命令说明目的、普通用户或 `sudo`、L0–L3 风险、执行上下文、采集范围和预期信号。危险操作单独呈现，并在获得授权前停止。
